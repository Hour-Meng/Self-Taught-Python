# Self-Taught Python (Organized)

This repository contains my self-taught Python learning files and small projects. Most lessons come from YouTube and other resources that I found useful while learning.

## How to Use This Repo

1. Start with **Basics**  
   Go to: `PycharmProjects/01_Python_Basics/`

2. Move into **Data Structures**, **Functions**, and **OOP**  
   These folders are meant to be browsed like a learning checklist.

3. Try the small **Projects**  
   Go to: `PycharmProjects/10_Projects/`

---

## Recommended Workflow

- Browse folders by topic and open the `.py` files to read and run them.
- If you use PyCharm (recommended), you can open the `PycharmProjects/` folder directly as a project.
