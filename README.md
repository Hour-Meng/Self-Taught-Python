# Self-Taught Python

A comprehensive collection of Python learning materials, exercises, and projects for self-learners progressing from beginner to advanced levels.

## 📚 Overview

This repository contains hands-on Python code examples, learning exercises, and mini-projects organized by skill level. Whether you're just starting out or refreshing your Python knowledge, you'll find practical examples to help you learn by doing.

## 🗂️ Repository Structure

```
Self-Taught-Python/
├── beginner/                    # Entry-level Python code
├── python refresh/              # Python fundamentals review
│   ├── Learning/               # Core Python concepts
│   └── projects/               # Beginner-friendly projects
├── pythonProject/              # Intermediate to advanced topics
│   ├── Learning/               # Advanced Python concepts
│   └── Game projects/          # Game development projects
└── python_exercise/            # Practice exercises
```

## 📖 Topics Covered

### Beginner Level
- Variables and Data Types
- Input/Output Operations
- Type Casting
- String Methods and Formatting
- Indexing and Slicing
- Conditional Statements (if/else)
- Loops (for, while)
- Collections (Lists, Tuples, Sets)
- Dictionaries
- Logical and Conditional Operators

### Intermediate Level
- Functions and Lambda Expressions
- Higher-Order Functions (map, filter, reduce)
- Exception Handling
- File Operations (reading, writing, moving, deleting)
- Random Module
- Math Operations

### Advanced Level
- Object-Oriented Programming (OOP)
- Classes and Objects
- Inheritance (Single, Multiple, Multilevel)
- Method Overriding
- Abstract Classes
- Duck Typing
- Args and Kwargs
- Method Chaining
- Walrus Operator
- Module Importing

## 🚀 Getting Started

### Prerequisites
- Python 3.x installed on your system
- A code editor or IDE (VS Code, PyCharm, etc.)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Hour-Meng/Self-Taught-Python.git
cd Self-Taught-Python
```

2. Run any Python file:
```bash
python "python refresh/projects/quiz game.py"
```

Or navigate to a specific directory:
```bash
cd "python refresh/Learning"
python "variable.py"
```

## 💡 How to Use This Repository

1. **Start with Basics**: Begin with files in the `beginner/` and `python refresh/Learning/` directories
2. **Practice Concepts**: Review individual concept files to understand specific topics
3. **Build Projects**: Try running and modifying the projects in the `projects/` directories
4. **Challenge Yourself**: Complete exercises in `python_exercise/` to test your knowledge
5. **Advance Further**: Move to `pythonProject/Learning/` for advanced OOP concepts
